# Bundled local face models

These model files are provided by the OpenCV Zoo project:

- `face_detection_yunet_2023mar.onnx` — YuNet face detector.
- `face_recognition_sface_2021dec.onnx` — SFace face recognizer.

Source: https://github.com/opencv/opencv_zoo
